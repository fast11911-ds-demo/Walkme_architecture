Core Component Roles

👁
Eyes + Hands

WalkMe

Browser overlay that reads live DOM in real time, extracting Clean JSON of the current screen state — field values, workflow position, UI context. Relays context to Joule; executes automated clicks and inputs on Joule's instruction. Action Bar surfaces next-step suggestions directly in the flow of work.

🧠
AI Brain

SAP Joule (on BTP)

Enterprise AI copilot on SAP BTP AI Foundation. Analyses screen context from WalkMe, matches against 2,400+ Skills and 350+ Agents, then decides the Next Best Action. Joule Studio lets developers build and extend agents. Supports multi-agent orchestration via A2A protocol.

🔌
Integration Bridge

SAP CPI (on BTP)

SAP Integration Suite connects SAP and non-SAP systems via 2,000+ pre-built templates. CPI APIs and integration flows can be converted into MCP tools via the MCP Gateway, enabling Joule agents to reach any legacy or third-party system. General middleware platforms (MuleSoft, Boomi) co-exist as parallel bridges.

🗄️
App Memory

WalkMe Accelerator

Pre-trained screen pattern library covering SAP S/4HANA, Salesforce, ServiceNow, Jira, SuccessFactors and more. Instantly recognises UI patterns on any supported app, accelerating Clean JSON extraction without custom scripting. Smart Highlights surfaces live cross-system data within the active app.

🔗
NEW · TechEd 2025

MCP Gateway 2025

Announced at SAP TechEd 2025. Exposes CPI APIs and integration flows as MCP tools, making any connected system reachable by Joule agents and third-party AI agents (Claude, GitHub Copilot, Amazon Q) without custom integration code. Governed, auditable, and RBAC-controlled. SAP HANA Cloud gained full MCP support in early 2026.

End-to-End Data Flow

User acts on any app screen → WalkMe reads DOM + Accelerator pattern-matches → Clean JSON extracted → Joule analyses context + matches Skills → Next Action decided → WalkMe Action Bar displays guide or auto-executes → if backend data needed: CPI calls target system → if external AI agent needed: MCP Gateway routes via open MCP standard → governed execution, fully auditable
MCP & A2A — 2025/2026 Announcements: At SAP TechEd 2025, SAP announced extensive MCP support across all business applications. The MCP Gateway (via Integration Suite) lets Joule agents communicate with any API or integration flow as an MCP tool — covering legacy SAP and third-party systems. SAP uses MCP internally (agent-to-tool, data access) and A2A externally (agent-to-agent across vendors, e.g. Joule ↔ Microsoft 365 Copilot). In 2026, SAP and Anthropic announced strategic integration of Claude into Joule via MCP, enabling Claude-powered agents to execute tasks across S/4HANA, SuccessFactors, Ariba, and third-party systems without custom code.
