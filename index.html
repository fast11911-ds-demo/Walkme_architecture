Data Flow 핵심 요약

WalkMe의 Accelerator가 복잡한 화면 요소를 매핑하여 Clean JSON 데이터로 정제하면, 이 데이터가 SAP BTP CPI(또는 레거시 미들웨어)를 타고 SAP Joule로 전달됩니다. Joule은 이를 바탕으로 판단하여 최적의 다음 액션을 가이드합니다.

아키텍처가 갖는 비즈니스 가치

단순한 UI 오버레이 가이드를 넘어, 백엔드 플랫폼(BTP) 및 코어 AI(Joule)와 결합하여 "컨텍스트 인지형 자동화(Context-Aware Automation)"를 완성합니다. 기구축된 미들웨어 생태계를 파괴하지 않는 유연한 확장성이 핵심입니다.
